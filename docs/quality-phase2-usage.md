# Подготовка изображения и пробная отшивка

Новые режимы подготовки экспериментальные и требуют проверки на ткани. Они доступны в существующем окне «Автоматическая оцифровка», рядом с физическим размером. Режим по умолчанию остаётся «Исходная обработка».

1. Задайте ширину в миллиметрах до построения областей. DPI файла не используется для назначения размера. При изменении размера или параметров перестройте предпросмотр: устаревший результат фоновой задачи не применяется.
2. Выберите «Бережная», «Стандартная», «Для малого размера» или «Контекстная (эксперимент)». Первые три — режимы этапа 2 с разными пределами ширины/цвета. Контекстная сохраняет Standard, затем делает один ограниченный обход плоских микрокомпонент по свидетельствам окружения. Это режимы обработки, а не откалиброванные профили ткани. При выборе нового режима отсечение по площади и пикселям отключается; явные пороги остаются в дополнительных настройках. Для воспроизведения опубликованных чисел герба задайте там прежние 0,1 мм² и 1 px явно: другой порог означает другой эксперимент.
3. Защитите важные детали существующей кистью защиты. Закрепите необходимые цвета в палитре. Если уменьшение разрешения уничтожает защищённую деталь или существенно меняет её цвет, увеличьте разрешение трассировки: приложение сообщает об этом и сохраняет текущий документ.
4. Постройте предпросмотр областей. «Исходник», «Маска», «Области», «Стежки» и «Изменения» используют общее положение и масштаб. Оранжевым отмечено реальное переназначение пикселей; прозрачным — исключённый фон. Для отключения новой обработки вернитесь к исходному режиму. Для возврата исключённой детали используйте существующую кисть восстановления.
5. Оцените отверстия, перемычки, редкие символы, обводки и соседние заливки. Компоненты, контуры, объекты, блоки и машинные команды — разные показатели сложности; уменьшение их числа само по себе не доказывает улучшение.
6. Нажмите «Создать вышивку» явно. Повторная генерация стежков из объектов сохраняет ручную геометрию. Повторная оцифровка исходника — отдельное действие; несовпадающие ручные решения не переносятся догадкой. Undo/Redo сохраняется.

При сохранении ELAB исходное изображение, альфа, исключения, защита, палитра и рецепт остаются в проекте. Старые рецепты без нового поля используют прежний режим. При сохранении прежнего режима новое поле вообще не записывается. Проекты с новыми режимами требуют обновлённого приложения; расширение ELAB и версия проекта 5 сохранены.

Алгоритм не соединяет отдельные островки, не превращает исключённый фон в белую заливку и не изменяет генераторы Running/Satin/Tatami или кодеки DST. В режимах этапа 2 плоские детали сохраняются ранним запретом; Contextual отдельно оценивает окружение, толщину, исходную цветовую ошибку и топологию. Закреплённые метки и явно защищённые компоненты не переназначаются. Автоматическая оценка не гарантирует смысл каждого слабоконтрастного символа — используйте защиту важной детали. Общий лимит сложности продолжает действовать. Если сохранение всех областей превышает 4096 объектов, не увеличивайте порог площади без осмотра исключаемых фрагментов.

В существующей диагностике доступен раздел «Причины решений подготовки»: первые причины по проходам и контекстная обработка, размерные группы 1 / 2 / 3–4 / 5+ px. Следующий обычный проход показан только как диагностика, его изменения не применяются. У контекстного обхода нет итеративного продолжения: второй шумовой островок может остаться, если его сосед уже инвалидирован; повтор того же импорта детерминированно даст тот же результат. Старый Standard оставлен для сопоставления.

Новая различающаяся пара Standard / Contextual находится в `outputs/quality-phase21-20261106/operations/motif/sewout-pair/`; старый пакет восьми образцов ниже сохранён. [Результаты этапа 2.1](quality-phase21-report.md) отделяют исправленные фрагменты, сохранность и технологические издержки. Ни GUI-проверка мышью, ни физическая отшивка в этом этапе не заявляются выполненными.

Для физической проверки используйте отдельный пакет `outputs/quality-phase2-20261106/sewout/`. В нём есть исходные ELAB, DST, схемы цветов, параметры и незаполненная форма наблюдений. Реальная машина и пяльцы в найденных проектах не указаны: их соответствие необходимо проверить перед отшивкой. Наличие проверенного DST не заменяет эту проверку и не подтверждает качество на ткани.

Точный результат измерений, команды и ограничения приведены в отчёте этапа; сгенерированные изображения и пользовательский герб остаются локальными.
