# Диагностика RAG этапа 2.1

Этот документ описывает локальную проверочную сессию. В публичном репозитории доступны исходники, тесты и проверочные инструменты; частные изображения, их производные, бинарники и каталоги `outputs/` не публикуются. Указанные пути и SHA256 обозначают локальные доказательства, а не доступные для скачивания файлы. Сборка приложения не требует этих частных данных: см. [BUILDING.md](../BUILDING.md).

Отчёт строится `tools/quality_phase21_rag_report.py` по сырым картам меток и отдельным summary. Никакие параметры сегментации или критерии не изменяются.

## Как читать причины

Первая причина взаимоисключающая: каждая компонента одного прохода попадает ровно в одну строку. Дополнительные условия пересекаются: их нельзя складывать между собой или с первыми причинами. Популяция перестраивается между проходами; сумма трёх проходов не является числом уникальных компонент.

Гистограммы раздельно показывают 1 px, 2 px, 3–4 px и 5+ px, количество компонент, пиксели и площадь. Общие оси используются для одинакового прохода/показателя всех доступных вариантов. Полные точные числа — CSV/JSON в локальном `outputs/quality-phase21-20261106/rag/report/`.

## Ablation относительно Standard этапа 2

Диагностика всех трёх обычных проходов по структуре JSON одинакова: `True`. Кандидат добавляет отдельную контекстную стадию. Для выбора AA применяется одно полное 8-соседнее кольцо; более строгое двухкольцевое условие сохранено как отдельная диагностическая ablation. Их потенциальные кандидаты не суммируются и не выдаются за фактические изменения.

## Ограничения

Прохождение сохранности не является абсолютным качеством рисунка. Проверка судьбы малых областей здесь рассчитана для герба без pinned/protected; такие защиты требуют штатного контракта импортера. Классы цветовой ошибки, топологического запрета и invalidation не объединяются в одну предполагаемую причину. Вычислительный лимит и наличие четвёртого допустимого шага различаются. Скрытая визуальная укрывистость не выводится из этой карты.

Гистограммы находятся только локально; пользовательский источник и производные не публикуются.
