Указанные пути и SHA256 обозначают локальные доказательства, а не доступные для скачивания файлы. Сборка приложения не требует этих частных данных: см. [BUILDING.md](../BUILDING.md).

`9a5729f7180c08e7f44929465e694e0517f79302`; рабочая копия исходников, Cargo,

## Сохранность

- Legacy и Standard этапа 2 остаются доступными с прежним поведением.
- Новый кандидат только по явному выбору; Legacy остаётся значением по умолчанию.
- Не терять ни одного ранее принятого пикселя; не создавать прозрачность.
- Не менять pinned-метки и защищённые компоненты. Pinned — одновременно
  неизменность выбранного цвета палитры и прежний запрет переназначения его
  меток; protected — явная защита исходных пикселей и всей их компоненты.
- Не терять правильные core/marked pixels независимого эталона; не ухудшать
  его топологию и физическое смещение границ. Все прежние пороги сохраняются.
- Не изменять исходный RGBA, альфа, cleanup, рецепты, пользовательскую геометрию,
  Undo/Redo, отмену и ключи устаревания worker. Генераторы и кодеки неизменны.
- Противоположные проверки: слабый островок / контрастная точка; кайма /
  белая деталь; шум / отдельный символ; просвет, перемычка, редкий цвет.

## Группы и гипотезы

Существующие группы tuning/holdout и их SHA256 не меняются. Все 19 случаев
старых трёх манифестов повторяются. Новые unit-примеры проверяют механизм,
а не определяют пороги на holdout. Физические 30/60/90 мм используют один
побайтово одинаковый PNG. Native-resolution проверяется отдельно.

Порядок: воспроизведение Standard; диагностика первых причин и пересекающихся
условий; выбор минимального решения; единственный запуск замороженного holdout.
Проверяемая гипотеза H1: плоскость источника сама по себе преждевременно
блокирует исправимые слабоконтрастные островки. Проверка соседства должна
предшествовать автоматическому решению неоднозначности. H2: значительная
часть REVIEW возникает раньше RAG и/или блокируется явным pinned-контрактом.
H3: три прохода могут оставить допустимые изменения; диагностический четвёртый
просмотр не должен автоматически становиться четвёртым изменяющим проходом.

Изменение принимается как экспериментальное только при выполнении сохранности,
независимом положительном противоположном тесте и измеримом исправлении хотя бы
одного реального участка или независимого проблемного мотива. Число объектов
не является целью. REVIEW не превращается в PASS по относительной сохранности.
Если строгие абсолютные критерии не выполнены, режим остаётся экспериментальным.

Покрытие: старый witness сохраняется; 0,30/0,40≈75% — калибровка параллельного
Tatami, не универсальный порог. Метрики считаются одинаково для всех вариантов;
верхний слой отдельно от подложки, Travel и закрепок. Эталон не изменяется для
кандидата. Дефект oracle допускается только с независимым объяснением и тестом.

Приватные изображения и производные хранятся только в исключённом outputs;
публикация и управление машиной не выполняются.

## Выбор после диагностики, до запуска кандидата на holdout

Standard побайтово воспроизведён на 19/19 случаях (DST/ELAB/планы/стежки).
Все 6751 исходно исключённые компоненты герба — по одному пикселю; площадь
0,0682318864 мм². Первый flat-source отказ: 6933 компоненты / 7167 пикселей.
Плоское окружение + близкий цвет: ноль подходящих компонент герба. Полный
контекст двух колец для микро-AA: 3 компоненты; одного кольца, совпадающего
с окрестностью топологической проверки: 153 компоненты / 160 пикселей.
Это потенциальное свидетельство, ещё не разрешение изменения: защита,
закрепление, freshness и topology проверяются отдельно. Dry probe старого
четвёртого прохода: 107 пикселей, его результат не применяется.

Выбран Contextual: точный Standard с прежними тремя проходами, затем один
неитеративный проход исключительно плоских микрокомпонент ≤4 px, bbox ≤0,55 мм
по обеим осям. Внутри заливки нужен полный двухпиксельный контекст в исходном
цветовом шаре 0,035 OKLab. На границе нужны два достаточно больших смежных
региона, ≥10% общей границы, реальный контакт этих регионов в полном кольце
радиуса 1 px, отсутствие третьих цветов там, фиксированный residual ≤0,035 и
положение внутри [0,15;0,85] отрезка между базовыми цветами. Одной плоскости
источника больше недостаточно ни для отказа, ни для переназначения. Полный
старый AA-проход не повторяется. После изменения все инцидентные компоненты
инвалидируются; следующая операция использует только свежие цели.

Это ограниченная гипотеза AA, не универсальная физическая модель смешения:
независимая цветная калибровка показала её ограничения. Намеренная промежуточная
точка точно на такой же границе остаётся семантически неоднозначной; нет
обещания сохранять любой мыслимый символ без явной защиты. Контрастные точки,
белые линии, отверстия, перемычки, изолированные символы проверяются отдельно.
Закреплённые метки никогда не переопределяются. Дальнейший подбор на holdout
не выполняется; при нарушении сохранности кандидат отклоняется, а не получает
новые допуски. Режим остаётся opt-in.
