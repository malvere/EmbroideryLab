# EmbroideryLab

Редактор машинной вышивки на Rust с нативным интерфейсом egui/eframe. Импортирует PNG/JPEG/SVG, сохраняет редактируемые проекты ELAB, показывает порядок стежков и экспортирует DST. Есть экспериментальный DSB.

Версия 0.5 добавляет редактор Satin: две стороны колонны, узлы и Безье, направляющие направления стежков, разделение и замкнутые обводки. Осевые линии можно очищать по ветвям, измерять и сглаживать с предпросмотром. Доступны маска областей, Undo/Redo, встроенный исходник и восстановление несохранённой работы.

[Скачать Windows x64](https://github.com/malvere/EmbroideryLab/releases/latest) · [Сборка](BUILDING.md) · [Изменения](CHANGELOG.md) · [Проверки](VALIDATION.md) · [CLI и работа с проектом](embroidery-engine/README.md)

В архиве выпуска находятся `embroidery-lab.exe` (редактор), `embroidery-cli.exe`, документация и лицензии зависимостей. Проверенная Windows x64 сборка запускается без Rust, MinGW и дополнительных runtime DLL. Отдельные EXE также доступны на странице выпуска. Русский язык включён по умолчанию, английский выбирается в интерфейсе.

## Быстрый пример CLI

```text
embroidery-cli satin-demo example.dst
embroidery-cli project artwork.png artwork.elab 100
embroidery-cli generate artwork.elab artwork.dst
embroidery-cli centerlines artwork.elab axes.dst 1 0.20
embroidery-cli satin-outline artwork.elab outline.dst 1 2.0 closed
embroidery-cli quality artwork.elab quality.json
```

Размеры задаются в миллиметрах; номера объектов и ветвей начинаются с 1. Машинные файлы не восстанавливают исходные редактируемые контуры или точные цвета нитей.

## Границы версии

Полуавтоматический Satin работает с простыми открытыми ветвями. Развилки, циклы и сложные углы требуют ручной правки. Это не автоматическое распознавание текста и шрифтов. Проверка плотности — геометрическая эвристика. Качество на ткани и работа конкретной машины не сертифицированы; DSB-экспорт остаётся экспериментальным.

Публичный репозиторий содержит независимые исходники и синтетические тестовые фигуры. Пользовательские изображения, образцы вышивки, их производные, исследовательские дампы и сторонние исполняемые файлы сюда не включены.
