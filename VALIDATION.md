# Проверки и ограничения

Версия 0.5.0, 1 ноября 2026. В исходной рабочей среде полный прогон дал **162 passed, 0 failed, 1 ignored**; отключённый тест требует внешнего установленного DSB-корпуса. Строгий Clippy, форматирование и сборка прошли. Rust-исходники, тесты, Cargo-манифест и синтетические fixtures в публичном снимке сверены с проверенными файлами; документация переписана для публичной сборки. Полный Rust-прогон из новой папки экспорта отдельно не заявляется.

## Публичный выпуск

- Оптимизированные Windows x64 EXE собраны с GUI и CLI; служебная функция framebuffer capture в выпуск не включена.
- Оба EXE проверены по PE imports: только системные DLL Windows, дополнительных runtime DLL не требуется. GUI запускается без консольного окна.
- Холодный запуск выполнен из пустой рабочей папки с системным PATH: CLI создал и прочитал синтетические DST/DSB; GUI создал окно и штатно завершился. Это smoke-проверка, не полная приёмка интерфейса.
- Synthetic-only `tools/quality_v05.py`: **7 случаев × 2 формата = 14 экспортов PASS**, **4 проверки отказа PASS**. Независимый reader pyembroidery 1.5.1 сверил квантованные проколы и машинные команды; повторное открытие ELAB сохранило машинные байты. Использован Pillow 13.0.0.
- В публичный Git не включены пользовательские samples, производные реальных рисунков, внешние машинные образцы, исследовательские дампы и прежняя Git-история. Синтетические regression fixtures остаются частью тестов.

Лицензии зависимостей, включая встроенные шрифты, прилагаются к ZIP. SHA-256 файлов выпуска опубликованы в `SHA256SUMS.txt` на странице Releases. Записи о сборке указывают публичную ревизию исходников.

## Границы проверок

Полуавтоматический Satin рассчитан на простые открытые ветви; циклы, развилки и сложные углы требуют ручной коррекции. Подсветка плотности — геометрическая эвристика. Тесты и запуск окна не подтверждают полный keyboard-only, high-DPI или screen reader сценарий. Физический stitch-out, ткань, нить и настройки конкретной машины не проверены; DSB writer экспериментальный.

Инструкции воспроизведения: [BUILDING.md](BUILDING.md).
